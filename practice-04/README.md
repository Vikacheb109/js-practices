## 5. Реализация модулей

| Файл | Назначение |

| `task-storage.js` | Сохранение, чтение и проверка JSON |
| `main.js` | Обработка событий, текущее состояние, связь остальных модулей |

### Функция updateTask

Функция изменяет название и приоритет выбранной задачи. Поля `id` и `completed` сохраняются. Используются `map()` и spread-синтаксис, поэтому исходный массив и изменяемый объект не меняются.

### Функция validateTaskDraft

Проверяет ID, название и приоритет.

В режиме создания требуется уникальный ID. В режиме редактирования используется существующий `editingId`.

При ошибке возвращаются сообщения для соответствующих полей; при успехе — нормализованные значения.

### Модуль хранения

`saveTasks()` записывает JSON с номером версии.

`loadTasks()` проверяет сохранённую строку и восстанавливает задачи. При повреждённых данных используется исходный список.

`removeSavedTasks()` удаляет только ключ текущего набора.

## 6. Создание и редактирование

Одна форма поддерживает два режима.

**Создание:** поле ID доступно, после успешной отправки добавляется новая задача.

**Редактирование:** ID заблокирован, название и приоритет заполняются из выбранной задачи.

Для обработки формы используется событие `submit` и `preventDefault()`.

Значения получаются через `FormData`, проверяются и передаются в функции сервиса.

После успешной операции сохраняется новый массив, обновляется интерфейс и выполняется запись в `localStorage`.

## 13. Вывод

В ходе практической работы были изучены HTML-формы, событие `submit`, объект `FormData`, стандартные ограничения HTML и прикладная проверка данных.

Была реализована возможность создания и редактирования задач через одну форму, а также сохранения данных браузера с использованием `localStorage`.

Для хранения применяется JSON с номером версии. После чтения выполняется проверка структуры данных. При ошибке используется исходный список задач.

Были сохранены функции предыдущих практических работ, а новая функциональность выделена в отдельные модули.

Приложение поддерживает добавление, изменение, удаление, фильтрацию задач, восстановление после перезагрузки и сброс сохранённых данных.
