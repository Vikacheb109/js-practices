`A → B → C → D → E → F`

### Ожидаемый результат исходного примера

```text
A: синхронный код
B: начало async-функции
C: конец синхронного кода
D: обработчик Promise
E: продолжение после await
F: задача таймера
```

### Собственное изменение

Добавлен дополнительный обработчик:

```js

});
```

Ожидаемый порядок после изменения:

`A → B → C → D → E → G → F`

## 6. Организация модулей

| Файл | Назначение |
|---|---|
| `api/server.mjs` | Готовый учебный HTTP-сервер |
| `api/data.js` | Данные задач и категорий на сервере |
| `src/api-client.js` | Формирование URL, GET-запросы, JSON, ошибки и отмена |
| `src/task-api.js` | Запросы задач и категорий, проверка схемы |
| `src/main.js` | Общий и индивидуальный сценарий в терминале |
| `src/variant.js` | Номер варианта и фильтры |
| `examples/event-loop.js` | Эксперимент с очередностью выполнения |

### buildUrl

Функция проверяет базовый адрес, соединяет его с путём и добавляет параметры через `URLSearchParams`.

Значения `false` и `0` сохраняются. `undefined`, `null` и пустая строка пропускаются. Исходный объект фильтров не изменяется.

### createApiClient

Создаёт общий HTTP-клиент, который отправляет GET-запросы с заголовком `Accept: application/json`.

Полученный ответ проверяется по статусу, `Content-Type` и формату JSON.

Используются `AbortSignal.timeout()` и `AbortSignal.any()` для ограничения времени ожидания и внешней отмены.

### createTaskApi

Использует общий клиент для получения задач и категорий.

Поддерживаются фильтры `completed`, `priority`, `categoryId` и `q`.

Проверяется структура полученных задач и категорий, уникальность идентификаторов и соответствие `meta.total` длине массива.

### loadInitialData

Задачи и категории запрашиваются независимо.

Оба запроса начинаются до общего ожидания:

```js
const tasksPromise = getTasks(filters);
const categoriesPromise = getCategories();

const [taskResult, categories] = await Promise.all([
  tasksPromise,
  categoriesPromise
]);
```

Это позволяет не ждать завершения первого запроса перед началом второго.

## 7. Виды ошибок

| kind | Причина | Ожидаемый пример |
|---|---|---|
| `http` | Сервер вернул ошибочный HTTP-статус | 404, 503 |
| `network` | Ответ сервера не получен | Остановленный сервер |
| `invalid-response` | Неверный JSON, тип ответа или структура данных | `/debug/invalid-json` |
| `timeout` | Истекло время ожидания | Задержка 150 мс при лимите 20 мс |
| `aborted` | Запрос отменён внешним сигналом | `AbortController.abort()` |
